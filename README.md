# Al Wissam Legal Translation | الوسام للترجمة القانونية

A premium, enterprise-grade web platform for **Al Wissam Legal Translation**, a UAE-certified agency established in 1998. The project features a modern, high-performance, and fully responsive design tailored for legal services, company formation, and document attestation.

## 🚀 Projec Overview
This platform serves as a digital hub for Al Wissam's clients, providing a seamless experience for requesting quotes, tracking orders, and exploring certified translation services in over 50 languages.

## 🛠️ Technology Stack
- **Core**: HTML5, Vanilla JavaScript.
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Modern Utility-First Styles).
- **Animations**: [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) for smooth UI transitions.
- **Icons**: [FontAwesome 6](https://fontawesome.com/).
- **Typography**: [Google Fonts - Cairo](https://fonts.google.com/specimen/Cairo) (Optimized for Arabic/English).
- **SEO & Performance**: 
    - GA4 Analytics Integration.
    - JSON-LD Schema (LegalService) for enhanced search results.
    - Content Security Policy (CSP) for robust security.
    - PWA (Progressive Web App) support with install prompts.

## ✨ Key Features
- **Multilingual Support**: Real-time toggle between Arabic (RTL) and English (LTR) with persistent UI state.
- **Interactive Tracking System**: A dedicated tracking page (`tracking.html`) with a dynamic timeline to show order progress (Review, Translation, Notarization, Ready).
- **Service Catalog**: Comprehensive breakdown of services like Legal Translation, Driving License conversion, Notary Public services, and Company Formation.
- **Conversion-Optimized UI**:
    - WhatsApp floating button with pulse animation.
    - Dynamic Navbar with scroll detection.
    - Mobile-friendly drawer menu.
    - PWA installation banner.
- **Price Calculator & Upload**: User-friendly interface for estimating costs and uploading documents for review.

## 📂 Project Structure
```bash
├── index.html        # Main landing page (Services, About, Contact, Stats)
├── tracking.html    # Order tracking portal with dynamic timeline
├── blog.html        # Blog/News section for agency updates
└── logo.png         # Main branding asset
```

## ⚙️ Setup & Deployment
Since this is a high-performance static site, it can be deployed instantly:
1. Clone the repository.
2. Open `index.html` in any modern browser.
3. For production, host on any CDN (Vercel, Netlify, Cloudflare Pages, etc.).

## 🔒 Security
The project implements a strict `Content-Security-Policy` to prevent XSS and unauthorized script execution, ensuring client data safety.
